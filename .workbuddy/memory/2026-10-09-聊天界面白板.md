# 2026-10-09（补充二）：聊天界面显示成"白板"的排查

## 现象
用户把整套聊天界面拷进 Client 并编译通过后，聊天窗口是一片灰白：只有搜索框、空白左栏、
空白右侧聊天区，底部按钮被屏幕边缘裁掉。怀疑"配件（资源）没加载"。

## 结论：资源没缺，缺的是样式表
- `rc.qrc` 里 **57 个资源全部编进 exe**（qrc_rc.cpp 有 12.5 MB，头像/搜索图标/loading.gif 都在）；
  截图里搜索框的放大镜图标**确实显示**了 —— 因为代码里直接写了
  `searchAction->setIcon(QIcon(":/res/search.png"))`，不依赖 qss。
- 真正原因：`Client/style/stylesheet.qss` 只有 **1365 字节 / 12 个选择器**，只管
  `#LoginDialog` / `#RegisterDialog` 和它们的子控件 —— **聊天界面一条规则都没有**。
  而 `res/` 里 `chat_icon / contact_list / settings / msg_chat / video_chat / voice_chat /
  smile / filedir` 那一堆 PNG **就是给聊天界面的 qss 用的**（命名与选择器一一对应）。
- 教程原版样式表：**17,653 字节 / 111 个选择器**。

## ⚠️ 重要发现：教程源码就在本机
`D:\Git\AAA-Repository\llfcchat`（`client/llfcchat/` 和 `server/`）。
这正是 StatusServer 那个失效属性表 `..\..\..\Git\AAA-Repository\llfcchat\...` 指向的路径。
以后缺什么样式表、原版 .ui、SQL 备份，都去这里找：
- `client/llfcchat/style/stylesheet.qss` —— 完整界面样式表
- `client/llfcchat/res/` —— 56 个图标
- `sql备份/` —— 建表 SQL

## 修复
1. 用原版 `stylesheet.qss` 覆盖 `Client/style/stylesheet.qss`；
   核对过**你的 12 个选择器原版全都有**（那 4 个"独有"只是颜色值不是选择器），
   原版也没有 `#head_label` 规则 → 你用 QPainter 画的圆形头像不受影响。
2. 把你自定义的淡青白登录页底色保留下来：
   原版 `background-color:rgb(255,255,255)` → 改回 `#e7fbfff6`。
   （注意样式表是 CRLF，正则替换时要用 `\r\n` 匹配）
3. `touch style/stylesheet.qss rc.qrc` 后重编（qss 在 rc.qrc 里，必须让 rcc 重跑）。
   - **坑**：链接时如果 `Hchat.exe` 正在运行，会报
     `cannot open output file bin/Hchat.exe: Permission denied` —— 先 taskkill 掉。
   - qss 在 qrc 里是 **zlib 压缩存储**的，`grep` 查不到选择器，要看 `qrc_rc.cpp` 的字节数变化
     （12,547,719 → 12,553,785，+6 KB，对应 qss +15 KB 压缩后）。
4. 结果：exe 75,941,917 字节（+1208），客户端启动正常。

## 另一个问题：窗口被撑爆屏幕
`Client/mainwindow.cpp:110` `MainWindow::SlotSwitchChat()` 里：
```cpp
this->setMinimumSize(QSize(1050,900));
this->setMaximumSize(QWIDGETSIZE_MAX, QWIDGETSIZE_MAX);
```
**教程原版 mainwindow.cpp 第 110-111 行也是一样的** —— 教程作者假设屏幕够大。
用户屏幕工作区高度不足 900（还要扣标题栏和任务栏），所以底部按钮被裁。
另外 `SlotSwitchReg` / `SlotSwitchLogin` **没有恢复窗口尺寸**，从聊天页切回登录页时窗口仍是这么大。
建议改成按 `QApplication::primaryScreen()->availableGeometry()` 自适应，尚未实施。

## 注意
- Windows Python 不认 MSYS 风格路径（`/d/...`），在 Python 里必须写 `D:/...`。
- PowerShell 调 `Add-Type` 会被安全策略拦；查屏幕分辨率这类用 Qt 代码更可靠。
