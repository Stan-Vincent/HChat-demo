# 2026-10-10（补充四）：拖图发送后切会话闪退

## 现象
登录 → 拖照片到对话框 → 发送（重复 3 次）→ 点击其他联系人 → 闪退。

## 服务端日志的决定性线索
```
msg_id is 1017   msg_len is 53
receive data is {"fromuid":3,"text_array":[],"thread_id":1,"touid":2}
[ GET  uip_2 ] failed
```
**`text_array` 是空数组，而且连续发了 4 次**（拖 3 张图点 3 次发送）。

## 根因 1：`on_send_btn_clicked` 末尾无条件发包（chatpage.cpp）
```cpp
for (...) {
    if (type == "text") { ... textArray.append(obj); }
    else if (type == "image") { pBubble = new PictureBubble(...); }   // ★ 不往 textArray 塞东西
    else if (type == "file") { }
}
qDebug() << "textArray is " << textArray;
textObj["text_array"] = textArray;          // ★ 全是 image 时就是空数组
emit ...sig_send_data(ReqId::ID_TEXT_CHAT_MSG_REQ, jsonData);   // ★ 空包照发
```
**已修**：加 `if (textArray.isEmpty()) { return; }`。

## 根因 2：图片气泡被塞进 _unrsp_item_map（chatpage.cpp）
```cpp
ui->chat_data_list->appendChatItem(pChatItem);
_unrsp_item_map[uuidString] = pChatItem;   // ★ 图片没有回执，却等一个永远不会来的回执
```
**已修**：改为 `if (type == "text") { _unrsp_item_map[uuidString] = pChatItem; }`。

## 顺带补的判空（切会话路径）
- `ChatDialog::slot_text_chat_msg`：`GetChatThreadByThreadId()` 可能返回 nullptr，原来直接 `thread_data->AddMsg(msg)`
- `ChatPage::AppendChatMsg`：`msg` 和 `GetUserInfo()` 都没判空

## ★★ 已加入崩溃日志（main.cpp）——以后闪退能直接定位
```cpp
SetUnhandledExceptionFilter(UnhandledExceptionFilter);   // 崩溃时写 exe 同级 crash.log
std::set_terminate([]() { writeCrashLog("std::terminate ..."); abort(); });
```
记录内容：时间戳 + `exception code`（0xC0000005 = 访问违例）+ **崩溃地址**。
下次闪退后看 `bin/crash.log`，把地址发我就能定位到具体模块。

**踩坑**：`QString::arg((quintptr)x, 0, 16)` 在 Qt6 + MinGW 下报
`expression cannot be used as a function`（重载歧义）。
那段 QString 构造本来就是多余的（下面已有 snprintf 版本），直接删掉即可。
另外 `(size_t)` 转换比 `(quintptr)` 在 MinGW 下更稳。

## 还没做的（图片消息要真正发出去需要）
`on_send_btn_clicked` 的 image 分支只是本地 new 了个 PictureBubble，
没有 emit 任何请求；服务端 `DealChatTextMsg` 也只解析 `text_array`。
要真发图片需要：协议加 msg_type 字段 → 服务端加分支 → `chat_message` 加列 → 接收端按类型渲染。
