### ★ 两个链接坑（重要）
1. **`CryptProtectData` 在 `crypt32.dll`，不是 `advapi32`** —— 链 advapi32 会报
   `undefined reference to __imp_CryptProtectData`
2. **`Hchat.pro` 里 `win32:LIBS` 的位置**：qmake 生成 `LIBS = <用户LIBS> <Qt静态库>`，
   用户 LIBS 在**前面**，所以库顺序没问题；但**不能把 `-ldbghelp` 之类的行覆盖掉**。

## ★★ Qt + windows.h 的类型冲突（踩坑记录）
```cpp
#include <windows.h>   // → rpcndr.h: typedef byte cs_byte;  与 QtCore 的 byte 撞名
                      // → error: reference to 'byte' is ambiguous
```
**解法**：在 include 之前定宏
```cpp
#ifndef WIN32_LEAN_AND_MEAN
#define WIN32_LEAN_AND_MEAN
#endif
#ifndef NOMINMAX
#define NOMINMAX
#endif
#include <windows.h>
#include <wincrypt.h>
```
`main.cpp` 和 `logindialog.cpp` 都已加上。

## 7. add_btn（添加好友按钮）点了没反应 —— 已修
你在截图里圈的那个按钮是 `chatdialog.ui` 里的 **`add_btn`（ClickedBtn）**，位于聊天窗口顶部。
`chatdialog.cpp` 构造函数里只给它设了样式状态，**漏了 connect**，所以点了毫无反应。

**已修**（`ClickedBtn` 继承 `QPushButton`，没有自定义信号，直接用 `QPushButton::clicked`）：
```cpp
connect(ui->add_btn, &QPushButton::clicked, this, [this]() {
    qDebug() << "add_btn clicked, switch to search mode";
    ShowSearch(true);
    ui->search_edit->setFocus();
});
```
