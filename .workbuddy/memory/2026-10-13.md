## 修复：登录后闪退（crossFadeStacked 在动画自身 finished 里 delete 自己）
用户反馈"登录后闪退"。根因：`animutil.cpp` 的 `crossFadeStacked` 原实现用**单个** QPropertyAnimation，在它自己的 `finished` 信号回调里 `delete anim` / `delete eff`——等于在信号发射途中销毁发射者，触发 use-after-free，崩溃恰好发生在淡出/淡入结束（约登录后 200ms），表现为"切到聊天页就闪退"。

- 改法：拆成 out / in 两段独立 QPropertyAnimation，各自 `DeleteWhenStopped` 自动回收；`eff` 在 in 的 finished 里 `stack->setGraphicsEffect(nullptr)` 后 `eff->deleteLater()`（eff 父对象为 stack，detach 后延迟删除，安全）。彻底消除"在自身信号里删自己"。
- 验证：`mingw32-make -j4` 无 g++ 编译/链接错误；`bin/Hcat.exe` 17:20:10 更新；post-link `copy` Error 127 仍忽略。请用户重跑验证登录→聊天不再闪退。

## 时间胶囊二连修：定位漂移 + 半透明底染灰文字
用户截图反馈：①时间胶囊离气泡老远（浮在长消息上方偏左）；②"好的，收到"消息文字变灰。

- 根因 1（位置漂移）：初版 `layoutTimeLabel()` 用**条目宽度反推角落位置**（Self→x=10 左上 / Other→width-w-10 右上）。条目在 QVBoxLayout 里的宽度随布局/窗口缩放变化，定位时机不对就漂移；且角落离气泡本身就远（宽条目里气泡只占一侧）。
- 根因 2（文字染灰）：胶囊背景用了 **rgba(255,255,255,0.92) 半透明**。Qt 会把半透明子窗口的合成结果写进父控件 backing store，子窗口隐藏后只补绘它自己的矩形，**旁边的消息文字残留发灰鬼影**（截图中"好的，收到"变灰、下方的"hi"正常，因为只有被 hover 过的那条受影响）。
- 修法：
  1. `layoutTimeLabel()` 改为**贴气泡定位**：用 `m_pBubble->geometry()`（气泡实时几何），垂直居中对齐气泡中线；Other(气泡在左)→胶囊在气泡右侧 +8px，Self(气泡在右)→左侧 -24px（避开 16px 状态图标）；x/y 都 qBound 夹在条目内。不依赖条目宽度，永远紧跟消息。
  2. qss `#chat_item_time` 改**不透明白底 #ffffff + 1px #e8e8e8 边框**（去掉 rgba）。
  3. eventFilter 的 Leave 分支加 `update()`：子窗口隐藏后强制整条重绘，清残留鬼影（双保险）。
- 验证：删 `debug/Hcat_resource_res.o` + `debug/chatitembase.o` 后 `mingw32-make -j4` 0 error；exe 23:10:56 更新。
- ★ 经验：Qt 里**浮动小部件（tooltip/角标）别用半透明背景**——合成残留会把附近文字染灰且不自愈；要半透明观感就用不透明白+浅灰边框模拟。另：给列表项加浮动子窗口时，定位要锚定"目标兄弟控件的实时几何"，不要用容器宽高反推。

## 文字发灰三连修：真凶是 QTextEdit 透明底
用户再截图：胶囊位置已正确（贴气泡左侧），但"好的，收到"文字仍发灰，且"选中的时候有可能会变灰"。

- 关键线索：第一张截图里胶囊在长消息上方（旧定位 bug），发灰的却是另一条消息"好的，收到"——说明**发灰的就是当前 hover 的那条自身**，与胶囊是否重叠无关，病根在文字渲染链。
- 真凶：`TextBubble` 的 QTextEdit 用 `background:transparent`，黑色文字直接画在透明背景上，再与 BubbleFrame 画的珊瑚/白气泡底色**合成**。hover 时间胶囊显示/隐藏会触发条目局部重绘，重绘时抗锯齿边缘与"透明"混合 → 文字整体发灰发虚，且不自愈（backing store 里残留）。这也解释了为什么改胶囊背景（rgba→不透明白）没用——问题从来不在胶囊，在气泡文字自身。
- 修法：`TextBubble::initStyleSheet(ChatRole role)` 给 QTextEdit **不透明角色色背景**（Self=`#ffd0b8` 珊瑚、Other=`#ffffff`，与 BubbleFrame 同色）+ `border-radius:9px`（与气泡同圆角，同色无缝）。文字永远画在不透明底上，彻底不依赖合成。
- 验证：`mingw32-make -j4` 0 error；textbubble.o 23:24:15、exe 23:24:30。
- ★ 经验：**自绘气泡里的 QTextEdit 别用 transparent 背景**——文字 AA 边缘与透明混合后再合成，局部重绘就发灰；给文字控件一个与气泡同色的不透明白底（带同圆角）是根治办法。QTextEdit 的 viewport 默认透明，QSS background+圆角能正常透出。
