# HChat 前端改造方案 · P1（设计系统基座）

> **怎么用**：每条提案都有 `保留 / 弃用` 勾选，在方框打 `x`（或写"保留/弃用"），最后填文末「选择清单」汇总发我，我就按你的选择实现；未标的按"推荐"处理。
> **范围**：本篇只定 P1「设计系统 + 标题栏 + 气泡」的视觉规范（不动业务逻辑）。P2 视觉打磨、P3 动效（morphicons 思路）后续另立。
> **参考定位**：morphicons（借"图标随状态形变 + 弹簧物理"的交互理念，Qt 用 `QPropertyAnimation`+线性 SVG 近似）；jeecg 前端skills（借信息架构/组件规范，不照搬技术栈）。

## 0. 目标与原则
- 目标：去"幼稚感"，建立一致、克制、现代的设计系统。
- 原则：先定 tokens 再改组件；每步可编译、可回退；只动 UI 不动业务。

## 2. 标题栏
**现状**：通栏橙色、厚重、占视觉重心。
**提案（轻量标题栏）**：
- 高 40px，底 = `bg-card`，底部 1px `border`；
- 左：会话标题（`text-1` / 14px / 500）；
- 右：窗口控制（最小化/最大化/关闭）12px 线性图标，hover 出 `bg-hover`，关闭 hover 出红 `#E5484D`；
- 去掉大色块，主色只作强调（不再整条橙）。
- 可选升级：无边框 frameless + 自定义拖拽区。

## 3. 消息气泡
**现状**：朴素圆角矩形、缺层次。
**提案**：
- 自己：右对齐；右下角小圆角（2px）形成"尾指"；见 3.1 选底色。
- 对方：左对齐 + 显示名字；白底 + 1px `border` + 深字；左下角小圆角。
- padding `10px 14px`；圆角 `10px`；max-width `60%`；
- 间距：同一人连续消息 `4px`，换人/跨时间 `12px`；
- 时间分隔：居中 `text-3` 小字 + 细线；
- 头像 32px、圆角 6–8px（偏现代，非正圆）。
