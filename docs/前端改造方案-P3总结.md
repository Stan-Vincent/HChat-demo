## 一、总体结论

**P3 动效已完成，P2 §6 次按钮组收敛已完成，前端改造方案（P1 / P2 / P3）至此全部落地。** 逐项状态：

| 项 | 状态 | 说明 / 证据 |
|---|---|---|
| P3-1 消息气泡入场 | ✅ 已完成 | 新增 `AnimUtil::revealItem`：新消息高度 0 → 自然高度展开（220ms OutCubic）。**刻意不用 `QGraphicsOpacityEffect` 做淡入**——`animutil.cpp` 注释证实 `_main_widget` 已挂 `QGraphicsDropShadowEffect`，往其子孙控件（气泡）再挂 opacity effect 会触发**嵌套 effect 崩溃**（登录→聊天闪退）。高度展开由布局自然接管，零嵌套风险。`ChatView` 加 `_animate_items` 开关 + `setItemAnimate()`；`chatpage::SetChatData` 历史批量加载时临时关闭动画，避免切会话时一堆气泡同时展开掉帧，实时收发消息仍走动画。 |
| P3-2 图标 morph | ✅ 已完成 | 重构 `SvgIconButton`：`reload()` 拆为 `rebuild()/render()/updateColor()/stateColor()`，normal / hover / press 切换时描边色做 ~120ms 交叉淡化（纯 pixmap 重绘，无崩溃风险）。侧边栏图标、密码「睁眼」等所有 `SvgIconButton` 实例自动获得该过渡。 |
| §6 次按钮组收敛 | ✅ 已完成 | 删 `stylesheet.qss` 中 `#return_btn/#cancel_btn/#varify_btn/#find_btn/#logout_btn` 描边硬编码组 与 `QPushButton#reg_btn` 硬编码兜底组，统一走 §9 `[role]` 体系（cancel=ghost、return/varify/logout=link、reg_btn=link）。`#find_btn` 经核查为**无对应控件的死引用**（全仓库仅 qss 引用），一并移除。保留 `#return_btn[role="primary"]`（注册成功页主按钮，role 作用域覆盖）与 `#apply_sure_wid #cancel_btn[state=...]`（独立上下文）。 |

## 四、遗留 / 需真机核验

- **P3 气泡入场观感**：是「高度生长」式而非淡入式，确认是否符合预期；若想要淡入，受 `_main_widget` 阴影嵌套 effect 限制不能简单用 `QGraphicsOpacityEffect`，需另辟路径（见 P2 §4 同类坑）。
- **§6 收敛后按钮外观变化**：`return_btn / varify_btn / logout_btn` 由描边按钮变为**文字链接**、`cancel_btn` 圆角 10px → 6px、`reg_btn` 不变——均属预期收敛，但依赖 `[role]` 选择器在 Qt 6.5.3 下稳定；若真机发现 role 选择器不稳，回退方式是把删除的硬编码组加回（建议以注释形式保留以便一键回退）。
- **SvgIconButton 交叉淡化**在侧边栏 / 密码眼等处的观感（120ms 是否顺滑）。
