- 客户端用 Qt 自带 MinGW 11.2（`/d/QT6/Tools/mingw1120_64/bin` + `/d/QT6/6.5.3/mingw_64/bin` 的 qmake），`qmake` + `mingw32-make -j4` 全量链接通过；`QMAKE_POST_LINK copy` 的 `Error 127` 为 cmd 内建命令坑（无害），已 `cp` 补齐 DLL/plugins，`ldd` 无缺失。
