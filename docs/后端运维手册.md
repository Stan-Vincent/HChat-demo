## 3. 本地开发：启动 / 关闭

### 3.1 前置
`start.bat` 会先检测 **MySQL 3308、Redis 6380** 是否在跑（没跑会提示，登录/验证码会失败）。这两个要你自己先起（服务或客户端）。

### 3.2 启动（在 `D:\QTcode\HChat\Start\` 下）
```bat
start.bat            :: 全量：4 个后端服务 + Qt 客户端
start.bat backend    :: 只起后端（VarifyServer + Gate + Status + Chat1 + Chat2），不起客户端
start.bat chat2      :: 全量但用 ChatServer2，不起客户端
start.bat gate       :: 只起 GateServer
start.bat status     :: 只起 StatusServer
start.bat chat       :: 只起 ChatServer(chat1)
start.bat varify     :: 只起 VarifyServer
start.bat client     :: 只起 Qt 客户端
```
- 每个服务会**弹一个独立 cmd 窗口**，标题带端口（如 `GateServer :8080`）。**关窗口 = 停该服务**。
- 客户端 exe：`Client\build\Desktop_Qt_6_5_3_MinGW_64_bit-Debug\bin\Hcat.exe`
  （它读**自己目录里的** `config.ini`，`[GateServer] host=localhost` 为本机、`<服务器公网IP>` 为连云）。

### 3.3 关闭
```bat
Start\stop.bat
```
按端口（50051/8080/50052/8990/50055/8991/50056）找到 PID 强杀，并顺带关掉客户端 `Hcat.exe`。
> 也可以直接关掉对应服务的 cmd 窗口。

### 3.4 本地日志
- **窗口实时输出**：每个 cmd 窗口就是该服务的 stdout。
- **spdlog 文件**（按天）：`GateServer\logs\gate_日期.log`、`StatusServer\logs\status_日期.log`
  （start.bat 把工作目录设在服务目录，所以日志落在 `<服务目录>\logs\`）。
- **客户端日志**：`Client\build\...\bin\client.log`（运行）+ `crash.log`（**闪退**看这个，含模块基址+每帧偏移，可 `addr2line` 定位）。

## 4. 云服务器（阿里云 ECS）

### 4.1 SSH 登录
本机（PowerShell / Git Bash 均可）：
```bash
ssh -i <你的SSH私钥路径> root@<服务器公网IP>
```
- 已禁用密码登录，**只能用这把密钥**（本机 `<你的SSH私钥路径>`）。
- 公网只开了 22 / 8080 / 8990 / 8991；MySQL 3308、Redis 6380、gRPC 全在内网 `127.0.0.1`，切勿对公网开放。

### 4.2 五个 systemd 服务（开机自启，已 enable）

| unit | 服务 | 端口 |
|---|---|---|
| `hchat-gate` | GateServer | 8080 |
| `hchat-chat1` | ChatServer | 8990 |
| `hchat-chat2` | ChatServer2 | 8991 |
| `hchat-status` | StatusServer | 50052 |
| `hchat-varify` | VarifyServer(Node) | 50051 |

### 4.3 常用启停命令（SSH 登录后在服务器上执行）
```bash
# 看状态
systemctl status hchat-gate --no-pager
systemctl list-units 'hchat*' --no-pager          # 五个一起看

# 单个启/停/重启
systemctl start   hchat-gate
systemctl stop    hchat-gate
systemctl restart hchat-gate

# 全部一起
systemctl restart hchat-gate hchat-chat1 hchat-chat2 hchat-status hchat-varify
systemctl stop    hchat-gate hchat-chat1 hchat-chat2 hchat-status hchat-varify

# 开机自启（已开启；如被关过可重新打开）
systemctl enable hchat-gate        # 关自启用 disable

# 数据库/缓存（服务的前置，重启服务前确认它们是 active）
systemctl status  mysql redis-server
systemctl restart mysql redis-server
```
> 依赖顺序：先 `mysql`/`redis-server` 就绪，再起 5 个 hchat 服务。unit 里已写 `After=mysql.service redis-server.service`。

### 4.4 健康检查（探活）
```bash
# 服务器上（本地回环）
curl -s http://127.0.0.1:8080/health
# 期望: {"mysql":"ok","redis":"ok","status":"ok"}

# 看端口是否在听
ss -tlnp | grep -E ':8080|:8990|:8991|:50052|:50051|:3308|:6380'
```
本机（连公网）：`curl http://<服务器公网IP>:8080/health`

## 5. 云上日志怎么看（重点）

### 5.1 `journalctl`（推荐，所有服务统一，持久化到 /var/log/journal）
```bash
# 实时跟踪（Ctrl+C 退出）
journalctl -u hchat-gate -f

# 最近 100 行
journalctl -u hchat-gate -n 100 --no-pager

# 今天的日志
journalctl -u hchat-gate --since today --no-pager

# 指定时间段
journalctl -u hchat-gate --since "2026-10-27 13:00" --until "2026-10-27 14:00" --no-pager

# 只看错误级别（journald 按优先级）
journalctl -u hchat-gate -p err --no-pager

# 五个服务一起跟踪
journalctl -u hchat-gate -u hchat-chat1 -u hchat-chat2 -u hchat-status -u hchat-varify -f
```
> `-u` 后面接单元名。看 varify（Node，收不到验证码先看它）：`journalctl -u hchat-varify -f`。

### 5.2 spdlog 落盘文件（Gate / Status 额外有按天文件）
```bash
ls -la /opt/hchat/GateServer/logs/      # gate_2026-10-27.log
ls -la /opt/hchat/StatusServer/logs/    # status_2026-10-27.log
tail -f /opt/hchat/GateServer/logs/gate_$(date +%F).log
```
> ChatServer/ChatServer2/VarifyServer 的日志走 journalctl（见 5.1）即可。

### 5.3 客户端日志（闪退必看）
本机 `Client\build\Desktop_Qt_6_5_3_MinGW_64_bit-Debug\bin\` 下：
- `client.log`：运行日志（最近的请求/交互）。
- `crash.log`：**闪退**记录，含 `module base` + 每帧 `off=0x...`。
  用 addr2line 精确到行（MinGW 无 PDB，dbghelp 认不出，要用这个）：
  ```bash
  D:/QT6/Tools/mingw1120_64/bin/addr2line -e Hcat.exe -f -C 0x140000000+<off>
  ```

## 7. 排障速查表

| 现象 | 先查什么 |
|---|---|
| 客户端"网络请求失败" | ① 客户端 exe 旁 `config.ini` 的 `[GateServer] host` 对不对（localhost/公网IP）；② 服务器 `journalctl -u hchat-gate -n 50`；③ 本机 `curl http://<服务器公网IP>:8080/health` |
| 收不到验证码 | `journalctl -u hchat-varify -n 100 --no-pager`（看 SMTP/Redis 报错） |
| 登录后连不上聊天/收发不到消息 | `journalctl -u hchat-chat1 -f`；确认 StatusServer 配置里 `[chatserver1/2] Host` = 公网 IP |
| 客户端闪退 | `bin\crash.log`（模块基址+偏移）→ addr2line 定位到行 |
| 登录/注册失败但服务在跑 | `systemctl status mysql redis-server`；`mysql` 库表是否正常 |
| 服务起不来 | `systemctl status hchat-xxx --no-pager` 看报错；`journalctl -u hchat-xxx -n 80` |
| 端口没监听 | `ss -tlnp \| grep :8080`；确认进程在跑且 config 端口对 |
